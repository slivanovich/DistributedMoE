# Заключение

Главным результатом работы является новая архитектура отказоустойчивого инференса больших Mixture-of-Experts (MoE) моделей на основе peer-to-peer коммуникаций. Достигнута независимость системы от конкретной архитектуры нейронной сети и возможность масштабирования на сотни GPU при сохранении производительности, сравнимой с традиционными коллективными подходами.

Для решения проблем традиционных коллективных коммуникаций (all-to-all) предложена P2P-архитектура с асинхронной диспетчеризацией экспертных вычислений. Система включает механизмы мониторинга состояния узлов, автоматического восстановления после отказов и динамической балансировки нагрузки. Реализованы два варианта Tensor Transfer Engine на основе MoonCake Transfer Engine и NVIDIA NIXL для эффективных межузловых передач данных через RDMA и NVLink.

Дополнительные эксперименты показывают, что выбор конфигурации системы существенно влияет на результаты. При тестировании различных комбинаций выравнивания памяти и групповых GEMM операций достигнуто улучшение производительности до 2.3x: лучшая конфигурация показала среднюю задержку 15.29 мс против 34.68 мс для базовой. Система демонстрирует стабильную работу в диапазоне размеров батчей от 1000 до 9000 токенов с пропускной способностью до 10.77 MB/ms.

При сравнении с традиционными коллективными подходами P2P-архитектура обеспечивает graceful degradation при отказах узлов. Система способна продолжать работу с пониженной производительностью при выходе из строя отдельных Expert Blocks, в то время как коллективные операции полностью останавливаются при любом отказе. Механизм Health Checker с периодичностью 100 мс обеспечивает быстрое обнаружение отказов и переназначение вычислений на альтернативные узлы.

Для подтверждения масштабируемости архитектуры проведено тестирование с 128 экспертами, распределенными по 2 Expert Blocks на отдельных GPU. Система показала способность обрабатывать контексты длиной до 8192 токенов при сохранении низкой задержки. Реализованная система метрик позволяет детально анализировать производительность на всех уровнях: от отдельных передач данных до полных forward pass операций.

Результаты экспериментов показывают, что P2P-подход является эффективной альтернативой коллективным коммуникациям для больших MoE моделей. Асинхронная природа P2P передач позволяет лучше перекрывать коммуникации с вычислениями, а отсутствие глобальных точек синхронизации повышает отказоустойчивость системы. Определены оптимальные конфигурации для различных сценариев нагрузки: grouped GEMM операции показывают лучшую производительность для высокой активации экспертов, а выравнивание памяти критично для низкой активации.

Таким образом, в рамках данной работы предложена и реализована практическая архитектура отказоустойчивого инференса MoE моделей с использованием P2P коммуникаций. В дальнейшей перспективе необходимо исследовать масштабирование на большее количество узлов, оптимизацию топологии P2P соединений, а также интеграцию с существующими фреймворками машинного обучения. Также представляет интерес разработка автоматических механизмов адаптации конфигурации системы под изменяющиеся паттерны нагрузки и создание библиотеки, реализующей предложенные техники для широкого использования в индустрии.
